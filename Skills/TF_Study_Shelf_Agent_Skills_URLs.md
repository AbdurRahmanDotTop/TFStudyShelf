# 11. Final Rule

**Optimize for the smallest set of high-quality skills that gives the TF Study Shelf agent strong coverage of Flutter, Dart, Firebase, Cloudflare, BLoC, Drift, AdMob, Clean Architecture, accessibility, performance, security, testing, QA, and deployment.**

The TF Study Shelf PRDs remain the source of truth for the actual product. Skills provide agent capabilities — PRDs define what to build.
